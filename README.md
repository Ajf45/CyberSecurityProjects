# Password Strength Checker - Python

A simple Python-based tool that evaluates the strength of user-entered passwords based on key criteria like length, complexity, and common patterns. Ideal for educational or security-awareness purposes.

🚀 Features
Checks for:

Minimum and maximum length

Uppercase and lowercase letters

Numbers and special characters

Common password patterns (e.g., "123456", "password")

Strength levels: Weak, Moderate, Strong

Customizable scoring logic

🛠️ Technologies Used
Python 3

re (Regex module) for pattern matching

📦 How to Use
Clone the repository

Run the script:

bash
Copy
Edit
python password_checker.py
Enter a password when prompted to get the strength analysis.
